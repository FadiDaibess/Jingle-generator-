# Jingle-generator-

Requirments: 
---------------
1. Breadboard
2. Jumper wire
3. 3x LEDs (Red, Green, Yellow).
4. 3x Resistor: 150 Ohm.  
5. Buzzer.
6. Microcontroller e.g Arduino Nano

   
You just need to replace the board’s output number at the top of the code with your board’s output port number.

// define pins 

const int ledLow = 4;  
const int ledMid = 5;   
const int ledHigh = 6;   
const int buzzerPin = 2;
